Start with the thing itself: the first concrete event, line or result, not a list of findings. Body paragraphs are plain <p> elements, direct children of the article. Inline code looks like W1[52,0] = 0.7 and never breaks across lines, so keep it short. A citation is a link to the reference list, such as Example et al. (2026).

A side note sits in the right margin on wide screens and opens in place when its number is tapped on a phone.A side note is one to three short sentences: a definition, a number, an aside that would break the paragraph. The text simply continues after it.
